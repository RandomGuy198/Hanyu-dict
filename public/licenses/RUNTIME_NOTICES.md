The application code in this repository is MIT and covered by the root `LICENSE`. The packages below are the runtime dependency tree this app installs for production, resolved through `package-lock.json`, plus the Workbox modules that the build copies into the service worker. No library is loaded from a CDN: every module this app executes is bundled and served from this origin. Where a browser build resolves a smaller subset than the tree npm installs (Node-only fallbacks behind a `browser` field, for instance), the subset is still listed here - naming a package you do not ship costs nothing, omitting one you do is a breach.
